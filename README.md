# Moving Arts Program

**Website: [movingartsprogram.com](https://movingartsprogram.com)**

Moving Arts Program (MAP) is a pro-bono live music and arts platform in Goa, India,
founded by filmmaker Prashant Kumar. We put on gigs, concerts and festivals in Goa:
the Grateful Dead Tribute, Rock Revival, Elvis Lobo, Unaccompanied and The Feni Trail.
